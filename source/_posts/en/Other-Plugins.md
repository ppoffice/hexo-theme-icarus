## Gallery

**Installation Guide**

The gallery plugin of Icarus contains both [lightGallery](https://sachinchoolur.github.io/lightGallery/) and
[Justified Gallery](https://miromannino.github.io/Justified-Gallery/) extensions.
It is enabled by default: `plugins` > `gallery` is `true` in the configuration file generated by Icarus.
If your configuration file does not have this setting, add it to enable the plugin.
To disable it, set it to `false`.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    gallery: true
{% endcodeblock %}

Additionally, in order to use Justified Gallery, wrap your images with the `<div class="justified-gallery">`
and `</div>` HTML tag pair.
Also, if you are using Markdown syntax to include images, add additional empty lines between the HTML tags and
Markdown tags.
For example, the Markdown code of the gallery preview below is

{% codeblock "Justified-Gallery-Markdown.md" lang:markdown >folded %}
<div class="justified-gallery">

![Elephant](/gallery/animals/elephant.jpeg)
![Dog](/gallery/animals/dog.jpeg)
![Birds](/gallery/animals/birds.jpeg)
![Fox](/gallery/animals/fox.jpeg)
![Horse](/gallery/animals/horse.jpeg)
![Leopard](/gallery/animals/leopard.jpeg)

</div>
{% endcodeblock %}

Meanwhile, we can use pure HTML to create Justified Galleries as well.
In this case, we will not need the empty lines between HTML tags.

{% codeblock "Justified-Gallery-HTML.md" lang:html >folded %}
<div class="justified-gallery">
<img src="/gallery/animals/elephant.jpeg" alt="Elephant" />
<img src="/gallery/animals/dog.jpeg" alt="Dog" />
<img src="/gallery/animals/birds.jpeg" alt="Birds" />
<img src="/gallery/animals/fox.jpeg" alt="Fox" />
<img src="/gallery/animals/horse.jpeg" alt="Horse" />
<img src="/gallery/animals/leopard.jpeg" alt="Leopard" />
</div>
{% endcodeblock %}

Note that the Markdown renderer adds your site's `root` to Markdown image paths automatically, but it leaves
HTML `<img>` tags as they are.
If your site is in a subdirectory (`root` in `_config.yml` is not `/`), write the subdirectory in the `src` of
HTML images yourself, but not in the paths of Markdown images.
For example, this site uses `root: /hexo-theme-icarus/`, so the HTML version would use
`/hexo-theme-icarus/gallery/animals/elephant.jpeg` while the Markdown version uses `/gallery/animals/elephant.jpeg`.

## KaTeX

**Installation Guide**

You can use the KaTeX plugin to render \\(\TeX\\) expressions.
To enable KaTeX, please set `plugins` > `katex` to `true` in your theme configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    katex: true
{% endcodeblock %}

Please also use `\\(` and `\\)` to wrap your inline expressions and `$$` or `\\[` and `\\]` pair to wrap 
block expressions.
For example,

{% codeblock Some-Post.md lang:markdown >folded %}
This is an inline expression: \\(ax^2+bx+c=0\\).

This is a block expression:
$$\displaystyle \frac{1}{\Bigl(\sqrt{\phi \sqrt{5}}-\phi\Bigr) e^{\frac25 \pi}} = 
1+\frac{e^{-2\pi}} {1+\frac{e^{-4\pi}} {1+\frac{e^{-6\pi}} 
{1+\frac{e^{-8\pi}} {1+\cdots} } } }$$

This is another block expression:
\\[f(x) = \int_{-\infty}^\infty\hat f(\xi)e^{2 \pi i \xi x}d\xi\\]
{% endcodeblock %}

Sometimes your \\(\TeX\\) syntax will be mistaken as Markdown syntax, which will result in rendering error.
For instance, the following equation will not work since it contains more than one `_` (underscores), 
which are mistaken for the italic text when processed by the Markdown renderer:

{% codeblock Some-Post.md lang:tex %}
$$
\hat{x}_{k}=\hat{x}_{k}^{-}+K_{t}\left(y_{k}\right)
$$
{% endcodeblock %}

In this case, you can either escape every character that may cause confusion:

{% codeblock Some-Post.md lang:tex %}
$$
\hat{x}\_{k}=\hat{x}\_{k}^{-}+K\_{t}\left(y\_{k}\right)
$$
{% endcodeblock %}

or simply wrap the whole equation with an additional pair of HTML tags:

{% codeblock Some-Post.md lang:tex %}
<div>
$$
\hat{x}_{k}=\hat{x}_{k}^{-}+K_{t}\left(y_{k}\right)
$$
</div>
{% endcodeblock %}

## MathJax

**Installation Guide**

You can use MathJax to render \\(\TeX\\) or MathML expressions.
To enable MathJax, please set `plugins` > `mathjax` to `true` in your theme configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    mathjax: true
{% endcodeblock %}

When using the \\(\TeX\\) syntax, please use `$` or `\\(` and `\\)` to wrap your inline expressions
and `$$` or `\\[` and `\\]` pair to wrap block expressions.
You can also use \\(\LaTeX\\) environments directly.
For example,

\\[f(x) = \int_{-\infty}^\infty\hat f(\xi)e^{2 \pi i \xi x}d\xi\\]

\\begin{equation}
A =

## Cookie Consent

**Installation Guide**

You can show a cookie consent dialog to your visitor by enabling the Cookie Consent plugin.
Please refer to [Download Cookie Consent](https://www.osano.com/cookieconsent/download/) and 
[Documentation for the Cookie Consent plugin](https://www.osano.com/cookieconsent/documentation/about-cookie-consent/)
for details on each configuration setting.
You can also disable the cookie consent dialog by commenting out the configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    cookie_consent:
        # The compliance type. Can be "info", "opt-in", or "opt-out"
        type: info
        # Theme of the popup. Can be "block", "edgeless", or "classic"
        theme: edgeless
        # Whether the popup should stay static regardless of the page scrolls
        static: false
        # Where on the screen the consent popup should display
        position: bottom-left
        # URL to your site's cookie policy
        policyLink: 'https://www.cookiesandyou.com/'
{% endcodeblock %}


## Outdated Browser

**Installation Guide**

You can use the Outdated Browser plugin to detect outdated browsers used by
your site's visitors and remind them to upgrade their browsers.
To enable it, please set `plugins` > `outdated_browser` to `true` in your theme configurations.
Click [here](https://bestvpn.org/outdatedbrowser/en) to see a live preview of this plugin.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    outdated_browser: true
{% endcodeblock %}


## Page Loading Animations

**Installation Guide**

Page Loading Animations are enabled by Icarus by default.
To disable it, please set `plugins` > `animejs` to `false` in your theme configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    animejs: false
{% endcodeblock %}

Also, to disable the page loading progressbar, please set `plugins` > `progressbar` to `false` in 
your theme configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    progressbar: false
{% endcodeblock %}


## Back to Top Button

**Installation Guide**

Icarus shows a button that takes your visitors back to the top of the page after they scroll down.
It is enabled by default: `plugins` > `back_to_top` is `true` in the configuration file generated by Icarus.
To hide the button, set it to `false` in your theme configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    back_to_top: false
{% endcodeblock %}


## PJAX

**Installation Guide**

With [PJAX](https://github.com/MoOx/pjax), clicking a link to another page of your site does not reload the
whole page.
Instead, Icarus fetches the new page in the background and only replaces the parts that change, such as the
navigation bar, the main content, and the sidebars, which makes moving between pages faster and smoother.
PJAX is enabled by default: `plugins` > `pjax` is `true` in the configuration file generated by Icarus.
If your configuration file does not have this setting, add it to enable PJAX.
To disable PJAX, set it to `false` in your theme configurations.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    pjax: true
{% endcodeblock %}

Some notes on PJAX:

- The comment section is replaced together with the main content, and the scripts of the comment plugin run again,
  so the comments of each new page are loaded.
- MathJax typesets the expressions of each new page again.
- The scripts of web analytics plugins are not run again after a switch, so that a visit is not counted twice.
  <a href="{% post_path en/Web-Analytics-Plugins %}#Matomo">Matomo</a>, <a href="{% post_path en/Web-Analytics-Plugins %}#Umami">Umami</a>,
  BuSuanZi, and the <a href="{% post_path en/Web-Analytics-Plugins %}#Waline-Page-View-Counter">Waline page view counter</a>
  count the pages that visitors switch to by themselves.
  Other analytics services may only count the first page that a visitor opens, unless they track page changes on
  their own.


## Prefetch

**Installation Guide**

Icarus can prefetch the page of a link to your site while the pointer of a visitor rests on it, or as soon as
they touch it on a touch screen, so that the page opens faster when they click it.
To enable it, set `plugins` > `prefetch` to `true` in your theme configurations.
`delay` is how long, in milliseconds, the pointer has to rest on a link before its page is prefetched (65 by
default), so that moving the pointer across links does not prefetch all of them.

{% codeblock _config.icarus.yml lang:yaml %}
plugins:
    prefetch: true
    # Or, with another delay:
    # prefetch:
    #     delay: 100
{% endcodeblock %}

Some notes on prefetching:

- Only the pages of your site are prefetched: not links to other sites, downloads, or files such as images
  and feeds.
  To leave a link out, add the `data-no-prefetch` attribute to it.
- Nothing is prefetched when the browser of the visitor asks to save data, or on a 2G connection.
- With PJAX, the switch to the page uses the prefetched page.
  Without PJAX, browsers that support speculation rules use it for the navigation.
  Other browsers prefetch it with `<link rel="prefetch">`, which they only use if your host allows the page to be
  cached.
